# Gun Core Demo

一个可以直接游玩的佣兵事务所短局 demo。玩家需要在 21 天内把声望提升到 60，同时维持资金、补给、隐秘值和佣兵状态。

## 运行方式

当前项目使用原生 ES modules。可以直接使用自带服务器：

```bash
node server.mjs
```

然后打开 `http://127.0.0.1:5173/`。

## 当前可玩循环

- 创建玩家代表角色
- 招募随机佣兵
- 查看契约公开情报，花钱调查细节或刷新不合适的契约
- 选择最多 4 名佣兵组成契约小队
- 接取契约并推进日期
- 自动结算契约成败、奖励、经验、压力、伤势和隐藏事件
- 使用黑市补给、地下医疗、清理痕迹主动救局
- 升级基地设施
- 每天支付基地维护费和佣兵假身份费用
- 资金不足会降低隐秘值，隐秘值越低休整期越容易遭到袭击
- 21 天内声望达到 60 即胜利；期限耗尽或隐秘值归零即失败

## 后续适合扩展的方向

- 增加角色特质和负面癖好
- 增加区域、势力声望和契约链
- 增加战斗或行动阶段的事件选择
- 增加训练、休假和更细的治疗系统
- 将数据拆成独立配置文件
- 迁移到 React/Vite 以支持更复杂的界面状态

## 当前结构

- `index.html`：入口壳，只挂载根节点、CSS 和主模块
- `js/`：主入口、路由、状态管理、工具函数
- `modules/`：人物、契约、短局目标、机甲、仓库、势力/基地压力等业务逻辑
- `ui/`：各系统的 DOM 渲染和事件绑定
- `data/`：示例职业、任务、设施、档案文本等配置
- `styles/main.css`：统一样式
