# Gun Core Demo

一个佣兵事务所管理原型。当前版本专注于基地、角色、招募、任务派遣和任务结算，不包含战斗细节。

## 运行方式

当前项目使用原生 ES modules。建议在项目目录启动一个静态服务器后访问：

```bash
python -m http.server 5173
```

然后打开 `http://localhost:5173/`。

## 当前可玩循环

- 创建玩家代表角色
- 招募随机佣兵
- 选择最多 4 名佣兵组成任务小队
- 派遣任务并推进日期
- 自动结算任务成败、奖励、经验、压力和伤势
- 升级基地设施
- 每天支付基地维护费和佣兵假身份费用
- 资金不足会降低隐秘值，隐秘值越低休整期越容易遭到袭击
- 声望达到 100 视为当前原型目标完成

## 后续适合扩展的方向

- 增加角色特质和负面癖好
- 增加任务事件文本
- 增加主线目标和区域解锁
- 增加角色治疗、训练、休假
- 将数据拆成独立配置文件
- 迁移到 React/Vite 以支持更复杂的界面状态

## 当前结构

- `index.html`：入口壳，只挂载根节点、CSS 和主模块
- `js/`：主入口、路由、状态管理、工具函数
- `modules/`：人物、任务、机甲、仓库、势力/基地压力等业务逻辑
- `ui/`：各系统的 DOM 渲染和事件绑定
- `data/`：示例职业、任务、设施、档案文本等配置
- `styles/main.css`：统一样式
