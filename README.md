# Gun Core Demo

Gun Core 是一个反战黑色幽默题材的佣兵事务所经营 demo。玩家通过 GMS 远程在 SSS 内战中招募 Gun、接取契约、建设基地、购买装备、支付隐秘费用，并把战争财转化成私人收藏。

当前项目是纯前端静态页面，使用原生 JavaScript ES Modules，不需要安装 npm 依赖。

## 零基础运行方式

### 第 1 步：安装 Node.js

如果你的电脑还没有 Node.js：

1. 打开 [Node.js 官网](https://nodejs.org/)
2. 下载 LTS 版本
3. 一路默认安装即可

安装完成后，可以打开命令行检查：

```bash
node -v
```

如果能看到类似 `v20.x.x`、`v22.x.x` 的版本号，就说明安装成功。

### 第 2 步：下载项目

如果你会用 Git：

```bash
git clone <你的仓库地址>
cd Gun-Core
```

如果你不会用 Git，也可以在 GitHub 页面点击：

```text
Code -> Download ZIP
```

下载后解压，然后进入解压出来的 `Gun-Core` 文件夹。

### 第 3 步：启动本地服务器

在项目文件夹里打开命令行，然后运行：

```bash
node server.mjs
```

如果成功，会看到类似：

```text
Gun Core demo running at http://127.0.0.1:5173/
```

### 第 4 步：打开游戏

在浏览器地址栏输入：

```text
http://127.0.0.1:5173/
```

然后就可以开始游戏。

## 常见问题

### 直接双击 index.html 可以玩吗？

不推荐。

本项目使用 ES Modules，直接双击 `index.html` 时，浏览器可能因为本地文件安全策略导致脚本无法正常加载。最稳妥的方式是运行：

```bash
node server.mjs
```

然后从浏览器打开：

```text
http://127.0.0.1:5173/
```

### 提示 `node 不是内部或外部命令` 怎么办？

说明 Node.js 没有安装成功，或者安装后没有重新打开命令行。

可以尝试：

1. 关闭当前命令行窗口
2. 重新打开命令行
3. 再输入 `node -v`

如果仍然不行，重新安装 Node.js LTS 版本。

### 端口 5173 被占用怎么办？

可以换一个端口启动，例如：

Windows PowerShell：

```powershell
$env:PORT=5174; node server.mjs
```

macOS / Linux：

```bash
PORT=5174 node server.mjs
```

然后打开：

```text
http://127.0.0.1:5174/
```

## 当前可玩内容

- 招募随机佣兵，并通过兵营提高佣兵上限。
- 调查契约情报，根据战斗力、敌方伤害类型、推荐武器、推荐能力和需求人数配置小队。
- 派遣最多 4 名佣兵执行契约，获得预付款、尾款、基地声望、个人声望、强化点和随机事件。
- 佣兵可通过契约晋升，晋升时提升基础战力并随机获得技能。
- 强化点可用于让佣兵基础战力 +20，或从训练池中学习技能。
- 管理佣兵伤势、压力、物理负面状态和精神负面状态。
- 使用医疗中心与娱乐中心处理不同类型的负面状态。
- 在支出页查看每日支出；生活补给不再囤货，会按佣兵评级自动折算为每日金钱开销。
- 使用黑市购买武器、防具和机甲。
- 升级基础设施，包括酒馆、兵营、防御设施、黑市、医疗中心、娱乐中心和情报室。
- 每月处理隐秘费用；未支付的声望会降低隐秘值，隐秘值越低越容易遭遇基地突袭。
- 在财富页购买私人收藏，买完整个收藏室后视为胜利。

## 项目结构

- `index.html`：页面入口。
- `server.mjs`：本地静态服务器。
- `js/`：主入口、状态管理、通知和通用工具。
- `modules/`：佣兵、契约、经济、战斗力、仓库、武器、防具、机甲和财富等业务逻辑。
- `ui/`：各系统的页面渲染和事件绑定。
- `data/`：契约、设施、训练池、经济和文本配置。
- `styles/main.css`：统一样式。
- `context/`：世界观与剧情背景记录。
- `docs/`：设计文档、术语表和测试流程文档。
- `reports/`：测试与平衡性报告。
- `tools/`：验证、模拟和构建辅助脚本。

## 修改后检查

项目中文文件统一按 UTF-8 保存。修改代码后建议运行：

```bash
node tools/verify-source.mjs
```

这个脚本会检查 JavaScript 语法，并扫描常见乱码片段，避免页面只剩背景但 UI 没有渲染。
