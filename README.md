# Gun Core Demo

一个佣兵事务所经营 demo。玩家通过 GMS 在 SSS 内战中远程招募 Gun、接取契约、维护基地、支付隐秘成本，并把战争财转化为私人财富收藏。

## 运行方式

当前项目使用原生 ES modules，需要通过本地静态服务器启动：

```bash
node server.mjs
```

然后打开：

```text
http://127.0.0.1:5173/
```

## 当前可玩循环

- 招募随机佣兵，并通过兵营提升佣兵上限。
- 调查契约情报，围绕战斗力、敌方伤害类型、建议职业、推荐武器和需求人数配置队伍。
- 派遣最多 4 名佣兵执行契约，获得预付款、尾款、基地声望、个人声望、强化点和随机事件。
- 管理佣兵压力、伤势、正面状态和负面状态。
- 使用医疗中心治疗负面状态。
- 在支出页面批准每日支出，并按需购买补给库存。
- 使用黑市购买武器、防具和机甲。
- 升级基础设施，包含酒馆、兵营、防御设施、黑市、医疗中心、娱乐中心和情报室。
- 每月处理隐秘费用；未支付的声望会降低隐秘值，隐秘值越低越容易遇袭。
- 在财富页面购买私人收藏，买完整个收藏室后胜利。

## 当前结构

- `index.html`：入口页面。
- `server.mjs`：本地静态服务器。
- `js/`：主入口、路由、状态管理、通知与工具函数。
- `modules/`：角色、契约、经济、战力、仓库、武器、防具、机甲和财富等业务逻辑。
- `ui/`：各系统 DOM 渲染与事件绑定。
- `data/`：职业、契约、设施、经济和文本配置。
- `styles/main.css`：统一样式。
- `context/`：世界观与剧情背景记录。
- `docs/`：设计与测试流程文档。
