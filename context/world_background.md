# 核心世界观背景：少年兵 / Gun-Core 共用背景

## 一句话概括

这是一个人类刚从对外星高等文明“天人”的灭绝战争中幸存下来，却立刻把用于保卫人类的机动兵器、矩阵技术与异源金属投入内战、镇压、雇佣兵战争和政治清算的反战机甲世界。

## 叙事基调

- 核心气质是残酷、反战、碎片化群像。
- 机动兵器不是浪漫英雄道具，而是把城市、儿童、士兵和社会结构一起碾碎的战争机器。
- 少年兵、弁卒、同步兵、难民、底层佣兵与地方武装都是这个世界的消耗品。
- 战争并不因“人类共同敌人”消失而结束。天人战争结束后，人类迅速回到内部压迫、派系清算、军阀割据和资源掠夺。
- Gun-Core 若沿用该背景，应避免把“佣兵发财”写成纯爽文。金钱、装备和声望背后应始终连着黑市、创伤、背叛、政治风险和战争财。

## 历史大背景

### 天人战争

“天人”是曾对人类发动战争的高等外来文明。人类在战争初期遭遇巨大毁灭，旧有国家体系、金融体系、全球网络与许多大城市被摧毁。

为了对抗天人，人类发展出一系列改变文明结构的技术：

- 机动兵器。
- 异源金属与异源机。
- 神经同步技术。
- 矩阵网络。
- 人造矩阵与远程供能体系。
- 同步兵、弁卒等围绕机动兵器形成的新兵种。

天人最终被盟军击败或至少被逐出主要战场，但战争留下的技术、信仰、创伤与军事组织没有消失。

### SSS 的崛起

SSS，全称为 Supra-National Security Solution，中文可理解为“超国界安全解决方案”。它是横跨亚非欧三大洲的军事同盟 / 超国家安全政体。

SSS 的崛起与领袖“仏铁”密切相关。仏铁率领光复军在天人战争中完成多次反攻，收复非洲、西亚与大半欧洲，被塑造成“人类不会失败”的象征。

SSS 的高层、军队和意识形态高度受般若洲影响。般若洲既是革命摇篮，也是 SSS 的权力核心来源之一。般若洲人在机动兵器同步率上具有显著优势，并在军政体系中享有更高信任。

### 仏铁的隐退

天人战争后，仏铁本可以建立无人能挑战的世界政权，但他选择隐退。史料暗示，他可能已经受到异源侵蚀，身体和精神状态恶化。

仏铁隐退后，其亲密战友组成的“元老院”逐渐控制 SSS 的军政经济资源。仏铁本人变成近乎宗教化的政治符号，而真正的制度权力被元老院把持。

## 继业者战争

继业者战争发生在天人战争结束约半个世纪前后，是 SSS 内部分裂引发的大规模内战。

直接背景：

- 仏铁长期失踪，SSS 失去不可替代的最高权威。
- 元老院垄断军政资源、异源技术和战略档案。
- 仏铁养子“后翼”成为监军，被文官系统、非嫡系军官、工业联合体与部分加盟国视为改革继承人。
- 后翼推动“联合审计行动”，试图清查军费、腐败、异源技术伦理、战争责任与重建经费。
- 元老院和纸鹤将审计视作派系清算与对光复军形象的破坏。
- 镇暴、罢工、加盟国退出、军事接管、后翼失踪和死亡等事件将冲突推向全面内战。

战争规模极大，PO 提到其将夺走全国近 3% 人口，死亡人数高达约 7000 万。

## 主要阵营

继业者战争中的势力常以颜色简称：

- 红军：支持纸鹤和元老院的中央军嫡系，是光复军中坚，装备精良，初始实力最强。
- 蓝军：支持后翼的中央军非嫡系、地方部队与改革派联合体，前期中规中矩，依赖外交和外援变强。
- 紫军：作壁上观、保持中立的中央军部队，立场摇摆。
- 绿军：地方本土武装，借机推翻 SSS 统治，实现独立。自由佣兵也可被归入此阵营。
- 黄军：不主动参与内战的地方本土武装或地方军。
- 白军：卷土重来的土匪、山贼、仆从国伪军等。
- 黑军：直属仏铁的亲卫队，是失去领袖的影子部队，不被 SSS 正式承认。
- 锈蚀：世界公敌式的极端组织，与一切势力敌对，行动不择手段，目标通常是制造混乱或达成极端目的。

Gun-Core 的佣兵组织可以合理存在于绿军、黄军、白军、蓝军外围、黑市网络或独立地下承包商之间。

## 关键地点

### 般若洲

SSS 的政治、军事与文化核心之一。般若洲人拥有特殊外貌与高同步率，被描述为“为战争世纪而生”的人群。他们数量稀少，寿命偏短，绝大多数被征召进军队。

般若洲文化对 SSS 的军队命名、代号制度和身份认同影响极深。

### 南极基地 / The Base

天人战争中建立的大型联合科研都市，位于南极冰盖与冰下岩层之间。它由北约、华约、般若洲及中立国共同建设，曾聚集全球科学家、工程师、数学家、军官和行政人员。

关键技术多诞生于南极基地：

- 机动兵器标准化体系。
- 初代人造矩阵。
- 异金冶炼。
- 神经同步。
- 异源机培育。
- 矩阵通讯。
- 护盾技术。

战后，南极基地没有解散，而是演化为独立政治技术势力“太学院”。太学院不直接统治国家，但掌握矩阵与异源研究核心技术，是人类文明延续的重要技术中枢。

### 矩阵节点

矩阵不只是通讯或能源系统，也是货币、身份、工业、军队和统治的基础设施。控制矩阵常常比控制土地更重要。

内战爆发后，各地矩阵节点脱离中央控制，地方政府、军阀、企业联盟和武装组织开始运营自己的小矩阵。

## 技术设定

### 机动兵器

机动兵器原本是人类制造来对抗天人的机甲装备。天人被击败后，它们成为人类内部战争的主要暴力工具。

机动兵器的强弱不主要取决于火力，而取决于异源金属浸润率。SSS 通常用“等级 Class”和“世代 Generation”描述机体。

等级大致如下：

- E 级：异金占比低，接近传统机械，便宜可靠，常用于殖民地守备、治安镇压和消耗战。
- D 级：量产主力，具备有限神经同步能力，对机师精神有轻微影响。
- C 级：半生物化特征明显，机体可能出现低级自主反应，机师会感到机体情绪。
- B 级：战略级机体，会响应驾驶员神经和情绪，长期驾驶可能导致人格侵蚀、记忆混杂和依赖。
- A 级：反天人机级别，接近人造异源生命，具备自修复能力和不可逆神经链接。
- S 级：极少量试作级战略资产，接近核武式神秘存在。

世代大致如下：

- 1G：机械世代，传统液压与电子控制，驾驶员死亡率高。
- 2G：神经世代，引入同步率，早期事故严重。
- 3G：矩阵世代，可接入矩阵，实现感知共享与远程供能。
- 4G：共振世代，强调驾驶员与异金精神适配，机体会保留前任驾驶习惯。
- 5G：畸变世代，接近天人技术，可模块重组、自我增殖、融合异金修复。

### 异源金属 / 异金

异源金属是天人战争中发现的战略资源，是异源机自我增殖后的产物。它具备高能量传导、高结构强度和信息承载能力，是先进机动兵器、矩阵核心和战略装备的基础。

异源金属既是资源，也是价值储备。在矩阵停摆、信用点失效、Marker 无人兑现时，异金仍能制造武器、驱动机器并换取资源，因此被称为“最后的货币”。

### 神经同步与异源侵蚀

驾驶高级机动兵器需要神经同步。同步率越高，机体响应越强，但精神风险也越大。

相关风险包括：

- 精神错乱。
- 脑死亡。
- 人格侵蚀。
- 记忆混杂。
- 对机体产生依赖或爱恋。
- 异源污染。
- 群体共感或意识边界消失。

适合成为机师的人，反而往往不是最渴望驾驶机动兵器的人。PO 将机动兵器比作“魔戒”：越向往它，越可能不适合它。

### 弁卒

弁卒是为机动兵器提供协同支援的高损耗兵种。他们配备轻型外骨骼、维修工具、牵引兵装和侦查设备，任务包括：

- 填补机体感知死角。
- 近距离护卫。
- 危险区域侦察。
- 战场维修。
- 标记目标。
- 火力诱导。
- 掩护机体撤离。

弁卒被军中视为“机体的外置装甲”。他们常来自囚犯、贫民、孤儿、偷渡客等边缘群体，死亡率远高于普通步兵。

### 同步兵

同步兵是将异源机植入人体的士兵。异源机会蚕食宿主血肉并自我复制，将身体逐步替换为异金骨架，使其能无视普通武器并搭载异源武器。

代价是生命进入倒计时，最终异源机会破坏大脑。

## 社会与文化

### 代号名制度 / Nama System

代号名制度是天人战争时期形成的军事与社会文化。盟军成员在服役期间使用统一的般若洲语代号，取代本名、姓氏、籍贯和民族称谓。

其目的包括：

- 保密与无线电通讯便利。
- 去民族化。
- 统一发音。
- 建立“旧我已死”的战时人格。

该制度缓解了民族矛盾，也强化了集体主义和服从文化。战后，北约和华约逐渐恢复传统身份体系，SSS 和般若洲势力则长期保留代号名文化。

### 战后信仰结构

天人战争后出现多种围绕天人、科技和仏铁的信仰：

- 回归：认为高科技暴露了人类位置，应去联网、低技术、反 AI。
- 进化：认为天人代表更高生命阶段，追求神经链接、记忆同步和群体共感。
- 天启：直接崇拜天人，认为天人是末日或神性具象，部分教派主动接受异源污染。
- 仏铁崇拜：将仏铁视为人类意志和世界精神的具现化，SSS 内部广泛存在。
- 殉身式战争宗教：由大战中的巨大死亡规模催生。

这个世界不再相信抽象制度，而转向崇拜“绝对存在”：天人、仏铁、矩阵、机体或战争本身。

## 经济与货币

### 信用点 / CP

信用点依附于矩阵存在。它不是实体货币，而是记录在矩阵网络中的信用协议。所有生成、转移、冻结、销毁与结算都必须通过矩阵。

优点是管理效率极高，缺点是统治者能实时追踪交易、冻结资产、限制账户权限，甚至决定信用点用途。

内战后，不同势力运营自己的矩阵节点，也发行各自版本的 CP，如 SSS CP、北约 CP、华约 CP 或般若洲 CP。

### 旧币与战争券

旧时代国家货币在天人战争中崩溃，被统称为旧币。战争初期曾发行战争券，用配给物资、燃料和军工产能背书。SSS 崛起后战争券退出主流流通，但仍作为历史遗产存在。

### Marker / 人情

Marker 是佣兵、情报组织、军火商与地下网络之间流通的特殊信用。它代表一次经认证的人情、承诺或未来帮助。

Marker 可分为：

- 个人 Marker。
- 组织 Marker。
- 派系 Marker。

在地下社会中，Marker 有时比货币更珍贵，因为它能换到不该出售的东西：军火、撤离机会、情报、通行权限或武装支援。

### 矩阵钟 / MC

矩阵钟是极罕见的战略资源，本质更接近矩阵底层授权令牌。持有者可调用矩阵权限，效果可能包括能源配额、生产线、远程运算、封存数据库、战略通讯甚至临时系统权限。

矩阵钟无法被常规制造，因此是最接近“权力”的价值单位。

## Gun-Core 可复用方向

当前 Gun-Core 的佣兵经营玩法可以自然接入以下设定：

- 玩家组织是内战时代的地下承包商 / 雇佣兵组织 / 安全公司。
- 契约来源可以来自红军、蓝军、绿军、黄军、白军、地方政府、企业联盟、黑市、太学院外围、锈蚀伪装委托等。
- 声望可以区分为公开声誉、地下 Marker 信用、阵营关系与矩阵记录。
- 隐秘值可解释为组织在矩阵与各派情报网中的暴露度。
- 黑市装备可来自战场回收、地方小矩阵产线、退役机动兵器拆件、异金走私。
- 医疗和精神状态应与异源污染、同步创伤、PTSD、弁卒消耗和战争宗教挂钩。
- 财富标签页可以保持反战讽刺：玩家用战争财购买豪宅、游艇、古董、慈善名誉、私人矩阵权限或不道德消费。
- 后续若加入机甲系统，机动兵器不应只是战力加成，而应带来高维护费、同步风险、精神侵蚀、政治通缉和矩阵依赖。
