# 训练池与状态系统设计

本文档记录当前 demo 中佣兵训练、技能标签、负面状态的设计方向。旧职业系统已经废除，不再使用职业大类、职业小类、推荐职业等字段。

## 训练系统

每名佣兵不再拥有固定职业。佣兵有两种成长来源：契约晋升和基地强化点。

## 契约晋升

契约成功时，每名参与并存活的佣兵会独立进行晋升判定。当前概率为：

| 当前评级 | 晋升概率 |
| --- | --- |
| 无等级 | 60% |
| F | 50% |
| E | 40% |
| D | 30% |
| C | 20% |
| B | 10% |
| A | 5% |
| S | 0% |

晋升成功时：

- 佣兵评级提高一级。
- 获得对应的基础战斗力加成。
- 从全技能池中随机获得 1 个尚未拥有的技能。

基础战斗力加成：

| 新评级 | 基础战斗力加成 |
| --- | --- |
| F | +2 |
| E | +4 |
| D | +8 |
| C | +16 |
| B | +32 |
| A | +64 |
| S | +128 |

## 基地强化点

契约成功时，每名参与并存活的佣兵都有 5% 的固定独立概率为基地获得 1 点强化点。这个概率不和晋升二选一；同一名佣兵可以既晋升，又为基地带回强化点。

强化点属于基地资源，不属于单个佣兵。

强化点有两种用途：

- 消耗 1 点强化点，让指定佣兵基础战斗力 +20。
- 消耗 1 点强化点，让指定佣兵学习 1 个技能。

## 强化点学习技能

玩家消耗基地强化点学习技能时：

- 玩家先选择一个训练池。
- 系统从该训练池中随机抽取最多 3 个该佣兵尚未拥有的技能。
- 如果可抽取技能不足 3 个，则显示 2 选 1 或 1 选 1。
- 如果某个训练池已经被该佣兵抽空，则该训练池不可选择。
- 玩家从候选技能中选择 1 个获得。
- 当前阶段技能只用于 UI 展示和契约能力匹配，暂不实现额外数值效果。

## 训练池

当前训练池包括：

| 训练池 | 主要标签 | 设计定位 |
| --- | --- | --- |
| 战斗训练 | 战斗、武器、突袭、近战 | 正面交火、突击、压制与直接暴力。 |
| 情报训练 | 情报、调查、隐秘、潜入 | 获取情报、降低未知风险、识别任务需求。 |
| 后勤训练 | 后勤、收益、补给、仓库、装备 | 成本、收益、补给、装备和账本管理。 |
| 生存训练 | 生存、医疗、精神、评估 | 降低伤病、压力和死亡带来的人员损耗。 |
| 通用训练 | 通用、生存、隐秘、武器 | 任何佣兵都可能掌握的杂项能力。 |
| 机师训练 | 机师、机甲、维护、火控 | 驾驶 Mobile Weapon 和处理机体风险。 |
| 特殊训练 | 特殊、污染、精神、回收 | 高风险、高不稳定性的异常处理能力。 |

训练池数据位于 `data/trainingPools.js`。

## 契约推荐能力

契约不再生成 `requirements.careerCategories`，而是生成 `requirements.skillTags`。

契约调查情报中的“推荐能力”会显示需要的小队技能标签，例如：

- 战斗
- 情报
- 生存 + 后勤
- 机师 + 特殊

结算规则：

- 小队拥有全部推荐标签：成功率获得小幅加成。
- 小队只满足部分推荐标签：按缺失数量扣成功率。
- 小队完全不满足推荐标签：额外扣成功率。

当前扣分公式：

```text
缺失标签数 * 10
如果一个推荐标签都没有满足，再额外 -6
```

## 状态系统关系

- 负面状态统一保存在 `character.conditions`。
- 物理负面状态使用 `category: "physical"`，通过 `woundPoints` 累计为伤势。
- 精神负面状态使用 `category: "mental"`，通过 `stressPoints` 累计为压力。
- 伤势先以固定值扣减战斗力，压力再以百分比折损剩余战斗力。

旧“正面状态 / 正面特性”系统已经被训练技能系统替代。后续如果需要正面效果，应优先作为训练技能效果实现，而不是恢复旧 `positiveConditions` 字段。
