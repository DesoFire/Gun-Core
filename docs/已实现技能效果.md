# 已实现技能效果

本文件记录第一批已经接入实际数值系统的训练技能效果。具体数值统一维护在 `modules/skillEffects.js`，角色详情中的“持有技能”会显示当前技能的实际效果说明。

## 已接入系统

- 战斗力：部分战斗、通用、机师技能会提高个人最终战力。例如武器熟练、火力压制、空手习惯、火控接管等。
- 契约成功率：部分技能会按契约类型、推荐能力匹配、已调查情报、高难度契约等条件提高成功率。
- 契约成本与收益：情报技能会降低调查费用；后勤技能会提高金币结算、预付款比例、战斗掉落率。
- 风险控制：生存、情报、通用、特殊技能会降低伤病、精神负面状态、死亡率、负面突发事件权重或隐秘损失影响。
- 运营成本：补给统筹会降低个人每日补给消耗；装备账本、仓库清点、机体维护类技能会降低装备维护费。
- 成长：临场学习会把契约成功后获得基地强化点的个人独立概率从 5% 提高到 8%。

## 暂缓深入实现

以下技能已经保留为轻量效果或占位，因为它们更适合等待对应系统完善后再展开：

- 机甲专属技能：等待 Mobile Weapon 的出战、损坏、维修、驾驶员适配等规则成型。
- 黑市深度议价：需要黑市 UI 和购买流程显示最终折扣。
- 治疗流程加成：需要医疗中心、娱乐中心支持按角色或按标签选择治疗目标。
- 工资、招募、隐秘费用细分：需要更精细的费用结算入口，否则容易让玩家看不到技能收益来源。
