# 职业与状态系统设计

本文档记录当前 demo 中佣兵职业、正面状态、负面状态的设计方向。项目仍处于快速迭代阶段，数据可以直接调整，不需要兼容旧存档。

## 职业结构

每名佣兵拥有一个职业小类，并由该小类归属到一个职业大类。

- 职业大类：提供统一定位和基础效果，用于契约推荐职业判断。
- 职业小类：提供额外专长，让同一大类下的佣兵产生差异。

## 职业大类

| 大类 | 定位 | 当前效果 |
| --- | --- | --- |
| 战斗类 | 正面交火、高危突破和压制火力 | 战斗力 +4；战斗契约成功率 +5 |
| 生存类 | 降低死亡、受伤和长期压力 | 死亡率 -2；压力增长 -10% |
| 情报类 | 降低契约不确定性，处理隐藏风险 | 调查费用 -10%；预留战力情报加成 |
| 后勤类 | 治疗、装备、收益和基地协同 | 契约金钱 +5%；后勤契约成功率 +4 |
| 异常类 | 处理异源、污染和精神风险 | 异常契约成功率 +6；预留精神严重度降低 |
| 成长类 | 初始不稳定，但更容易成长 | 初始战斗力 -3；成长触发概率 +10 |

## 契约建议职业

契约会生成 `requirements.careerCategories`，表示建议参与的大类，例如：

- `战斗类`
- `情报类`
- `情报类 + 战斗类`

结算规则：

- 队伍满足全部建议大类：成功率 +4。
- 队伍只满足部分建议大类：不获得加成，并按缺失数量扣成功率。
- 队伍完全不满足建议大类：额外扣成功率。

当前扣分公式：

```text
缺失大类数 * 10
若一个建议大类都没有满足，再额外 -6
```

## 状态系统关系

- 正面状态：来自升级或消耗强化点，提供战斗力、死亡率降低、压力恢复等正面效果。
- 身体负面状态：来自契约受伤、失败或防护不匹配，影响战斗力、伤势、压力和死亡率。
- 精神疾病：压力达到 100 后触发，触发后压力归零，并获得中度或重度精神疾病。

职业、正面状态和负面状态共同影响契约成功率、战斗力、死亡率、受伤率和压力曲线。
