# Gun Core 术语标准化盘点

本文档记录游戏内中文术语与代码字段的对应关系。新增机制时优先沿用这里的代码标准名，避免再次出现“契约/任务”“职业/技能”等混用。

## 核心规则

| 概念 | 中文显示名 | 代码标准名 | 备注 |
| --- | --- | --- | --- |
| 契约 | 契约 | `mission` | 游戏里统一叫“契约”。代码里统一使用 `mission`，不再新增 `contract`。 |
| 基础设施 | 基础设施 / 设施 | `facility` / `facilities` | 单个设施用 `facility`，集合用 `facilities`，不再新增 `building`。 |
| 娱乐中心 | 娱乐中心 | `entertainmentCenter` | 不保留旧“医务室”命名。 |
| 医疗中心 | 医疗中心 | `hospital` | 处理物理负面状态。 |
| 情报室 | 情报室 | `intel` | 用于降低调查费用。 |
| 防御设施 | 防御设施 | `defenses` | 按数量叠加基地防御战斗力。 |

## 资源与基地

| 概念 | 中文显示名 | 代码标准名 | 备注 |
| --- | --- | --- | --- |
| 资金 | 资金 / 金 | `gold` | `gold` 是数值，“金”是单位。 |
| 补给 | 补给 | `supplies` | 库存资源，由支出页购买并按佣兵评级消耗。 |
| 基地声望 | 基地声望 | `reputation` | `state.reputation` 只表示基地声望。 |
| 个人声望 | 个人声望 | `personalReputation` | 不再使用“知名度”。 |
| 强化点 | 强化点 | `enhancementPoints` | 属于基地资源，不属于单个佣兵。 |
| 隐秘值 | 隐秘值 | `stealth` | 隐秘费用配置在 `secrecy` 下。 |
| 未遮掩声望 | 未遮掩声望 | `unpaidSecrecy` | 每月未支付隐秘费后累计。 |

## 佣兵

| 概念 | 中文显示名 | 代码标准名 | 备注 |
| --- | --- | --- | --- |
| 佣兵 / Gun | 佣兵 | `mercenary` / `character` | 世界观里 Gun 是佣兵代称；旧 UI 模块仍有 `character`。 |
| 名册 | 人员 / 佣兵名册 | `roster` | 已雇佣佣兵列表。 |
| 招募池 | 招募名单 | `recruitPool` | 可招募候选人。 |
| 评级 | 评级 | `rank` | 无等级、F、E、D、C、B、A、S。 |
| 训练技能 | 训练技能 / 技能 | `skill` / `skills` | 保存在 `character.skills`。 |
| 训练池 | 训练池 | `trainingPool` / `trainingPools` | 数据位于 `data/trainingPools.js`。 |
| 技能标签 | 能力标签 / 技能标签 | `skillTags` | 用于契约推荐能力匹配。 |
| 当前状态 | 状态 | `status` | 待命、执行中、阵亡等可用性状态。 |
| 档案 | 档案 | `dossier` | 角色背景信息。 |

## 战斗与状态

| 概念 | 中文显示名 | 代码标准名 | 备注 |
| --- | --- | --- | --- |
| 战斗力 | 战力 / 战斗力 | `combatPower` | UI 概览可用“战力”，详情说明用“战斗力”。 |
| 基础战斗力 | 基础战力 | `baseCombatPower` | 裸人战斗力。 |
| 装备战斗力 | 装备战力 | `equipmentCombatPower` | 当前主要来自武器。 |
| 技能加成 | 技能加成 | `skillBonus` | 当前预留为 0，未来技能效果可接入。 |
| 负面状态 | 负面状态 | `condition` / `conditions` | 物理和精神负面状态都在 `character.conditions`。 |
| 物理负面状态 | 物理负面状态 | `physicalCondition` | `condition.category === "physical"`。 |
| 精神负面状态 | 精神负面状态 | `mentalCondition` | `condition.category === "mental"`。 |
| 伤势点数 | 伤势点数 | `woundPoints` | 由物理负面状态累计。 |
| 伤势等级 | 伤势 | `injuryState` | 无伤、微伤、轻伤、中伤、重伤、濒死。 |
| 压力点数 | 压力点数 | `stressPoints` | 由精神负面状态累计。 |
| 压力等级 | 压力 | `pressureState` | 无压、低压、中压、高压、极限、崩溃。 |

## 契约

| 概念 | 中文显示名 | 代码标准名 | 备注 |
| --- | --- | --- | --- |
| 契约 | 契约 | `mission` | 代码层统一为 `mission`。 |
| 契约面板 | 契约面板 | `missionBoard` | 位于 `economyConfig.missions.missionBoard`。 |
| 执行中契约 | 执行中 | `activeMissions` | `mission.status === "active"`。 |
| 可接契约 | 可接 | `availableMissions` | `mission.status === "available"`。 |
| 契约类型 | 契约类型 | `missionTypes` / `mission.type` | 护送、运输、侦察等。 |
| 契约难度 | 难度 | `mission.difficulty` | 显示为 F-S 标签。 |
| 战力需求 | 战力需求 | `powerRequirement` | 调查后以区间方式显示。 |
| 推荐能力 | 推荐能力 | `skillTags` | 契约五项调查情报之一，匹配小队技能标签。 |
| 推荐武器 | 推荐武器 | `weaponTypes` | 契约五项调查情报之一。 |
| 敌方伤害类型 | 敌方伤害类型 | `damageTypes` | 与防具防护类型对应。 |
| 需求人数 | 需求人数 | `recommendedTeamSize` | 契约五项调查情报之一。 |
| 突发事件 | 突发事件 | `missionRandomEvents` | 契约执行过程中的随机事件。 |
| 战斗掉落 | 战斗掉落 | `combatLoot` | 契约成功和基地防守成功都可触发。 |

## 装备与仓库

| 概念 | 中文显示名 | 代码标准名 | 备注 |
| --- | --- | --- | --- |
| 仓库 | 仓库 | `inventory` | 保存武器、防具、机甲等物品。 |
| 装备槽 | 装备槽 | `equipmentSlot` | 当前保留武器、防具。 |
| 武器 | 武器 | `weapon` | `slot: "weapon"` 或 `itemCategory: "weapon"`。 |
| 防具 | 防具 | `armor` | `slot: "armor"` 或 `itemCategory: "armor"`。 |
| 装备等级 | 装备等级 | `rarity` | F-S，不要与佣兵评级混用。 |
| 武器战斗力 | 武器战斗力 | `weapon.power` | 黑市武器按同级佣兵战斗力比例生成。 |
| 伤害类型 | 伤害类型 | `damageType` | 武器属性。 |
| 防护类型 | 防护类型 | `protectionType` | 防具属性。 |
| 回收价 | 回收价 | `sellValue` | 通常为原价 50%。 |
| 养护费 | 养护费 | `maintenanceCost` | 武器、防具无论是否装备都需要养护。 |

## 弃用字段

| 字段 | 状态 |
| --- | --- |
| `contract` | 不作为新代码命名使用，统一改为 `mission`。 |
| `building` | 不作为新代码命名使用，统一改为 `facility`。 |
| `infirmary` / 医务室 | 不再保留，统一为 `entertainmentCenter` / 娱乐中心。 |
| `notoriety` | 旧“知名度”字段，统一迁移为 `personalReputation`。 |
| `careerCategory` / `classId` / `className` | 旧职业系统字段，只允许在旧存档清理代码中出现。 |
| `positiveConditions` | 旧正面状态字段，只允许在旧存档清理代码中出现。 |
